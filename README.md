# 🎾 Tennis Scoreboard (Табло теннисного матча)

Веб-приложение для ведения счета теннисных матчей в реальном времени. Проект реализован в рамках обучения архитектурному паттерну MVC(S) и работе с протоколом WSGI без использования готовых фреймворков.

🚀 **Живое демо:** [http://91.200.84.196:8000/](http://91.200.84.196:8000/)

---

## ✨ Особенности проекта

* **Custom WSGI Framework:** Вся логика маршрутизации, парсинг параметров запроса и обработка HTTP-методов реализованы вручную в `app.py`.
* **Сложная бизнес-логика:** Реализованы правила тенниса: система 15/30/40, Deuce/Advantage (ровно/больше), тай-брейки и матчи из 3-х сетов.
* **Stateless Match Engine:** Текущий счет хранится в БД в формате JSON. Это позволяет корректно возобновлять матч после любых сбоев.
* **Оптимизация БД:** Использование SQLAlchemy 2.0. Запросы оптимизированы с помощью `joinedload`, чтобы избежать проблемы N+1 при выводе истории матчей.
* **Контейнеризация:** Приложение полностью готово к деплою через Docker.

## 🛠 Технологический стек

* **Backend:** Python 3.12, Waitress (WSGI сервер)
* **Database:** PostgreSQL
* **ORM:** SQLAlchemy 2.0
* **Шаблонизатор:** Jinja2
* **Frontend:** Чистый HTML/CSS (адаптивная верстка без Bootstrap)
* **Инфраструктура:** Docker, Docker Compose, Adminer (для управления БД)

## 🏗 Архитектура приложения (MVCS)

Проект разделен на слои для соблюдения принципа единственной ответственности:



[Image of Model View Controller architecture diagram]


* **Model:** SQLAlchemy модели (`models.py`), описывающие сущности Игрока и Матча.
* **View:** Шаблоны Jinja2, находящиеся в папке `templates`.
* **Controller:** Логика обработки маршрутов в `routes.py`.
* **Service:** Слой `service.py`, который связывает веб-часть с бизнес-логикой и базой данных.
* **Score Logic:** Изолированные классы `Match` и `Player` в папке `score_logic`, которые отвечают только за правила тенниса.

## 🚀 Быстрый запуск (Local Dev)

1.  **Клонируйте репозиторий:**
    ```bash
    git clone <ссылка-на-твой-репозиторий>
    cd tennis-scoreboard
    ```

2.  **Настройте переменные окружения:**
    Создайте файл `.env` и заполните его:
    ```env
    DB_NAME=tennis_db
    DB_USER=postgres
    DB_PASS=postgres
    DATABASE_URL_psycopg=postgresql+psycopg2://postgres:postgres@postgres:5432/tennis_db
    ```

3.  **Запустите проект:**
    ```bash
    docker-compose up -d --build
    ```

4.  **Доступ к приложению:**
    * Приложение: [http://localhost:8000](http://localhost:8000)
    * БД (Adminer): [http://localhost:8080](http://localhost:8080)
